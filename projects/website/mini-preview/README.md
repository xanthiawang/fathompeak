## 打开

在官网源码根目录运行：

```sh
python3 -m http.server 8857 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8857/mini-preview/>。页面用相对路径引用资源，交接时要保留整个官网仓库。不需要构建，也不需要安装依赖。

## 定位与页面

小程序以低价模型 API / Token 销售为主，在线试用是辅助选型的入口。

底部有四栏：模型市场、API 接入、体验、我的。

- **模型市场（首页）**
  - 头图和账户余额合在一张卡里：头图下方的半透明白条显示余额和"立即充值"（企业成员显示"企业分配额度"和"联系管理员"）。
  - 下面依次是：注册礼包与教育优惠卡片、"充值前，先算算费用"入口、模型目录（可搜索、按厂商筛选）、企业采购咨询。
- **模型详情**：输出参考价和计费条件；可以带着当前模型去算费用、去充值或去接入。
- **算算费用**：有三个入口，分别是首页卡片、"我的"菜单、评审导航第 2 项；从模型详情也能进入。
  - 填预计的输入 / 输出用量（单位：百万 Token）和公开单价，显示公开价预算、4 折预算和节省金额。
  - 返回按钮回到打开它的那一页。
- **API 接入**：账户余额、API Key 管理入口和接入步骤；配置页可以复制 Base URL 和模型名。
- **体验**：选模型、输入任务、在本机保存草稿；不生成假响应。
- **我的**
  - 头图卡的背景是官网登录页的插画（握手与山峦），靠右铺开、向左渐隐进登录页同一组渐变里；头像和标题在左侧天空部分，余额条和首页样式一致。
  - 下面是注册礼包、教育优惠，以及菜单：用量账单、算算费用、充值订单、发票与售后、API 接入、账户与安全、企业采购与合作、帮助与联系等。企业管理员多一项"成员与额度"。
- **充值**：填写金额，核对账户与模型意向，然后停在"支付未开通"状态。充值进入统一的账户余额，不是某个模型专属的包，也不承诺固定的 Token 数。

画框外的身份选择器只供设计评审使用。正式产品沿用官网的个人 / 企业独立登录，由后端做身份与权限校验。

## 价格与折扣口径

- 对外口径是**"公开价 4 折起"**（Zixin 2026-10-18 确认）。首页、模型详情、充值确认、服务说明、计费说明，以及礼包和教育弹窗都已统一。
- 首页副标题里的"4 折起"用品牌蓝、半粗无衬线字高亮，数字略大。
- 算算费用按最低的 4 折计算（`catalog.js` 的 `discountRate = 0.4`），并注明"实际折扣以模型与用量为准"。各模型的实际折扣档位还没有公布。
- 模型目录来自官网 `index.html` 的 `var M`：7 个模型，采集于 2026-10-13，只有输出参考价。历史目录价不再额外叠加折扣；输入单价、缓存单价和完整计费表还要接入。

## 视觉规范

依据仓库的 `design/palette-type.html`、`design/DESIGN_HANDOFF.md`、`fonts/fonts.css`，以及官网首页 `#home2` 的实测样式。

- **色卡**：晨蓝 #2F63B8、暮紫 #3D314F、墨色 #212021、纸白 #F8F8F8。图标 #4E3F66，底色为暮紫 7.5%。
- **面板**：半透明白底，圆角 16px，细边线，轻阴影。主视觉卡圆角 20px。
- **字体**
  - 标题：Fraunces + Noto Serif SC，字重 400，字距 −0.025em。
  - 正文与界面：DM Sans + Noto Sans SC，15px。
  - 金额与价格：Fraunces 的等高等宽数字（lining + tabular-nums）。
  - 小号标签、厂商名、筛选胶囊：DM Mono。
  - 按钮：DM Sans 500，15px。
- **插画**
  - 首页头图：排线钥匙（`art/console/engraved-dark-atlas_2026-10-14.webp`）加树影背景（`art/backgrounds/api-key-dapple-blue_2026-10-14.webp`）。钥匙完整放在卡片内，不出血。
  - 卡片插画：天平用于算算费用，罗盘用于企业采购，都取自同一张排线图集。
  - "我的"头图：官网登录页的 `art/account/engraved-ascent_2026-10-14.webp` 作为卡片背景，只露出握手和山峦，避开画面自带的文字；左侧用遮罩渐隐，不加画框。背景渐变为 #DCE7F7 → #E3DCE6 → #EBDDE0。
- **动态**：首页树影缓慢移动；可以在右上角"更多"里暂停，页面切到后台时自动暂停，并遵循系统的减少动态设置。

## 数据与接入边界

- 余额统一显示新账户场景 ¥0.00；企业成员的分配额度显示"—"。这不是从后台查到的数据，正式版必须区分加载失败、未登录和真实的零余额。
- 密钥列表是"尚未读取"状态，创建按钮禁用，不生成伪密钥。支付、订单、邀请、模型调用都没有接入。
- 68 元注册礼包是方案预览：不发券，不模拟到账。教育优惠只展示认证流程。
- 充值金额和模型意向按评审身份存在 sessionStorage；草稿存在 localStorage，可以在界面里清除。
- 算电协同基座、一体机、能源与算力节点合作，都通过采购咨询承接。

## UX 评审后的修改（2026-10-19）

依据 `04_调研与测试/小程序界面/小程序UX评审_2026-10-18.html` 的 5 个优先问题：

- **价格**：模型列表和详情里的历史公开价改成中性灰，标"公开参考价"；每行加"沐仞价 4 折起 · 待公布"，详情页写明价格表公布后显示。没有推算任何沐仞价。
- **算算费用**：
  - 单价区默认展开，写明去哪里找；
  - 加"快速填写 各 1 / 10 / 100"；
  - 全角数字自动转成半角；
  - 报错写明是哪个框，并滚到底栏上方；
  - "计算费用"改为主按钮；
  - 结果里加"按 ¥x 充值 →"，把折后预算带入充值金额（企业成员不显示）。
- **微信适配**：右上角改成不可点的微信胶囊占位；原"更多"里的服务说明、首页背景动态、关于沐仞移到"我的"；所有外链和邮箱改成"复制链接 / 复制邮箱"。
- **一致性**：主按钮统一品牌蓝，每屏一个；API 页"创建 API Key"改为次按钮并去掉重复入口；"购买 / 补充额度 / 充值购买"统一为"充值"；计费说明统一叫"计费说明"；用量账单去掉重复的 ¥；返回行去掉"沐仞 · AI 服务"。
- **可读与触控**：首页头图加强白色叠层，"4 折起"和"计费说明"改深蓝；通知、返回、胶囊、文字按钮的点击区不小于 44px；小标签 12px；占位提示加深。
- 充值页加 ¥100 / ¥500 / ¥1000 快捷金额。

验证：390 和 320px 下首页、API 接入、体验、我的、算算费用、充值都没有横向溢出，控制台无报错。测算 10M + 10M、单价 2 / 8 → 公开价 ¥100、4 折 ¥40，"按 ¥40.00 充值"带入金额 40.00。此改动只在本地，尚未推送。
