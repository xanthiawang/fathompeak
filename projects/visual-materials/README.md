# 沐仞 UI 视觉交付包（网页版）

在线浏览和逐个下载沐仞官网与后台的色彩、字体、图标、插画、品牌标识和页面截图。

- 首页 `index.html` 是设计说明；「全部文件下载」一节可以逐个下载文件。
- 内容来自 `02_品牌与文案/UI视觉交付包_2026-10-16`，用 `python3 build_site.py` 重新生成。
- 字体为 SIL Open Font License（见 `02_字体文件/hand-fonts-OFL.txt`）；第三方 Logo 版权归各自公司。
