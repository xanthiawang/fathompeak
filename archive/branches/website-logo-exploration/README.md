## 2026-10-14 Every 视觉逻辑研究与修正

参考：https://every.to/ ，在 2026-10-14 实际打开首页，对照文章封面、邮票横幅、产品卡和功能图标。以下是观察与设计推断，不是 Every 官方设计规范。

| 参考样例 | 灰度主体 | 彩色层与含义 | 可迁移逻辑 |
| --- | --- | --- | --- |
| 公司共享 Agent 封面 | 古典建筑、计算机设备 | 蓝色天空、橙色线路 | 历史物件与新技术拼接，线路承担连接语义 |
| 模拟与审批封面 | 雕像与手部 | 蓝色浮动人物卡片、深色底 | 将抽象思考外化为彩色符号，夸张比例形成视觉隐喻 |
| AI 使用习惯封面 | 人物、桌面 | 暖黄底与蓝色椭圆 | 人物动作与彩色符号发生关系，色块承载概念而非给人物染色 |
| 个人 benchmark 封面 | 写作者、电脑 | 蓝底、白色高低块、亮色尺子 | 背景组织节奏，测量道具承担语义；同图多种色彩分工 |
| 编码安全封面 | 孩子、插座 | 浅黄底、局部冷色处理 | 以熟悉场景表达复杂风险，主体清楚、背景简单 |
| 软件打磨封面 | 桥、岸线 | 紫蓝水面与黄色悬浮光块 | 超现实的彩色物件改变灰度场景，表达抽象行为 |

- **主体层**：主要人物/物体通常是灰度或低彩度的摄影、雕像、实物剪贴，保留体积、阴影和轮廓，不是统一描边的小图标。
- **色彩层**：背景、几何色块、道具与概念符号各自有作用，同一图像形成多色关系。蓝、灰紫、浅桃、纸白可同时在一张沐仞封面里出现，深紫提供结构。不能将整图改成蓝紫双色，也不能只在六张图之间分别换一种底色。
- **构图层**：遮挡、剪切、比例反差与异质对象组合形成隐喻；统一来自拼贴方法、印刷颗粒和层次关系，不来自所有对象的同一种透视/描边。
- **纹理层**：细颗粒、半色调和轻微印刷痕迹连接照片与色块；应避免给所有画面加发光和朦胧雾气。
- **不同用途**：文章封面采用彩色编辑拼贴；邮票横幅是另一套双色印刷模块；产品标识有独立几何/字标；搜索、菜单和箭头仍是克制功能线条。不要用邮票雕版概括全站，也不要把复杂插画缩到 18px 导航里。模型服务商既有 logo 保持身份辨识。
