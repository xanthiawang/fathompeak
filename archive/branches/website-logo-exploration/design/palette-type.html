04 / 插画与动态背景

插画采用黑白排线、版画质感主体，搭配不规则品牌深色色片，透明边缘融入卡片；功能 icon 继续使用轻量 SVG 线条。素材为 PNG / WebP，不是分层 PSD。

API Key 背景采用蓝色树影底图，模糊 7px；树影 10 秒、光层 13 秒往返循环，负延迟 −4 / −5 秒。仅在场景可见、标签页可见且未暂停时播放；尊重 prefers-reduced-motion，提供暂停按钮。
