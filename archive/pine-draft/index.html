常见问题

和直接用官方 API 有什么区别？

模型是同一个，请求格式兼容。区别在价格随时段的变化：官方在高峰时段涨价，沐仞的价格由电站侧的绿电供给决定，高峰不加价；每笔订单还附电站与减排记录。 怎么切换 →

"平价窗口"是什么意思？

某个模型在某个时段由富余绿电供给、按空闲价计费，这段时间就是它的平价窗口。每个模型每天的窗口不同，在模型市场和峰谷价格页都能看到，也可以订阅提醒。 怎么排进窗口 →

延迟会不会比官方高？

调度会在可承受的延迟边界内选择电站，不同任务可以设置不同的延迟要求；具体数值以文档中的服务等级说明为准。

绿电账单能用来做什么？

订单级的电站、度数与减排量可以导出为凭证，用于企业 ESG 报告、绿色采购和投标材料。 怎么写进 ESG 报告 →

需要先充值吗？

注册即赠送试用额度，可以直接调用；超出额度后再充值，并在充值前完成实名。

企业采购、开发票、签合同怎么办？

注册时选企业账号，认证后可开专票、签合同、加子账号、申请专属报价。采购量大或需要出海通道的，走企业与出海页联系销售。 企业与出海 →

快速开始

三步接入：拿到 Key，把 base_url 改成沐仞，发第一条请求。

1. 获取 API Key

在 获取 API Key 注册，试用额度自动到账，Key 只显示一次。

2. 把 base_url 指向沐仞

# OpenAI 格式
base_url = "https://api.fathompeak.cn/v1"
# Anthropic 格式
base_url = "https://api.fathompeak.cn/anthropic"

3. 发第一条请求

curl https://api.fathompeak.cn/v1/chat/completions \
  -H "Authorization: Bearer $FP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-5.3-flash","messages":[{"role":"user","content":"今天哪个电站在发电？"}]}'

返回后，控制台会立刻显示这笔请求的用量、成交电站与减排量。

鉴权与 Key

所有请求通过 Authorization: Bearer 头携带 Key。Key 以 fp-sk- 开头，可在控制台创建多个、分别命名并随时吊销。

按项目拆分

建议每个项目一个 Key，用量与账单会按 Key 分开统计，方便做成本分摊和绿电凭证归属。

泄露处理

在控制台吊销后立即失效；吊销不影响已完成订单的账单与凭证。

模型与计费

按 Token 计费，单位为 ¥ / 百万 Token，输入、输出、缓存命中分开计价。价格随时段变化：平价窗口内按空闲价计费，窗口外按当时价格。

平价窗口

每个模型每天的窗口由电站侧绿电供给决定，在模型市场、峰谷价格页和控制台都能看到；窗口开始前可以收到提醒。

绿电记录

每笔请求记录成交电站、消纳电量与减排量，按订单汇总到账单，可导出凭证。

错误码

每个错误都给出原因与修复步骤。

码原因怎么处理
401Key 无效或已吊销到控制台重新创建 Key
402试用额度用完充值前完成实名，充值后立即恢复
429触发限流按返回头里的 retry-after 重试；需要更高并发请联系我们
503当前窗口内该模型无可用节点自动回退到其他节点；可在请求里关闭回退并等待下一个窗口

延迟与服务等级

调度在任务可承受的延迟边界内选择电站。请求里可以声明延迟要求，调度只会在满足要求的节点之间选择价格最低的。

延迟等级

标准、低延迟、批量三档；批量任务可以完全跟着窗口走，价格最低。

可用性

单个节点不可用时自动回退到其他节点，账单上会标明实际成交的电站。

指南与活动

照着做的指南：切换、排窗口、选模型、上线检查；电站接入与分成；凭证写进 ESG，再加一页给老板的话术。不用注册，不留邮箱。

企业会问的

词元出海有牌照吗？

有网信办批复的词元出海资质，出海运营主体在汕头。合规文件可在签约前提供。

数据会不会出境？

来数加工在境内合规处理；具体数据流向按合同约定，签约前可做安全评审。

能开专票、签合同、对公转账吗？

企业账号认证后都可以。

有没有 SLA？

按延迟等级分级承诺，具体数值在合同的服务等级附件里；高峰时段的供给是沐仞的重点。

能私有化，或部署在我们自己的电站吗？

可以。一体机可部署在客户电站或机房，由沐仞远程运营。 电站合作 →
