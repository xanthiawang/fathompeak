## 如何修改

`index.html` 是可直接编辑的完整源码，包含 HTML、CSS 与 JavaScript。无需安装依赖或构建。样式在 `<style>` 中，页面内容在主体中，交互与页面路由在 `<script>` 中。字体由 Google Fonts 加载，访问环境可能影响字体加载。

登录 GitHub 后可以点击文件右上角的铅笔编辑，或在仓库页按 `.` 打开在线编辑器。有写入权限的协作者可提交到 `main`；其他人可 Fork 后提交 Pull Request。公开仓库不会自动授予所有人写入权限。提交到 `main` 后，GitHub Pages 自动更新对应网站。
